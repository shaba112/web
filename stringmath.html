1. String Functions

JavaScript provides many predefined string functions for text manipulation.The String object is used to work with text (a sequence of characters). We can use String methods to perform operations such as finding the length of a string, converting letters to uppercase or lowercase, and extracting parts of a string. 

text.length 
text.toUpperCase() 
text.toLowerCase() 
text.trim() 
text.charAt(6) 
text.indexOf("s")
text.replace("Java", "ECMA")
text.slice(1, 5)
text.concat(" is awesome!")

2. Math Functions

JavaScript Math object provides mathematical constants and functions.The Math object is a built-in JavaScript object used to perform mathematical calculations. It provides properties and methods for mathematical operations such as finding square roots, rounding numbers, finding maximum and minimum values, and generating random numbers.

Math.PI 
Math.sqrt(25) 
Math.pow(2, 3) 
Math.abs(-10) 
Math.ceil(4.3) 
Math.floor(4.9) 
Math.round(4.5) 
Math.random() 
Math.max(10, 20, 30) 
Math.min(10, 20, 30)
